# KhazarLLMs Landing Page

Рекламно-информационный сайт-визитка (лендинг) для проекта KhazarLLMs.

## 📋 Описание

Это профессиональный одностраничный лендинг, созданный для привлечения внимания целевой аудитории проекта KhazarLLMs и увеличения количества контрибуторов.

## ✨ Основные особенности

- **Современный дизайн**: Темная тема с градиентами и анимациями
- **Адаптивность**: Полностью responsive дизайн для всех устройств
- **Интерактивность**: Плавные анимации, переходы и эффекты
- **SEO-оптимизация**: Правильные мета-теги и структура
- **Информативность**: Полное описание проекта, функций и возможностей

## 📁 Структура

```
docs/
├── index.html      # Основная HTML страница
├── styles.css      # Стили и дизайн
├── script.js       # JavaScript функциональность
└── README.md       # Эта документация
```

## 🎯 Основные секции

1. **Hero Section** - Заголовок с призывом к действию
2. **Philosophy** - Философия проекта с цитатой
3. **Features** - Ключевые возможности (6 карточек)
4. **Agents** - Описание всех 7 AI-агентов
5. **Quick Start** - Примеры установки и использования
6. **Examples** - Примеры использования
7. **Contribute** - Призыв к контрибуции
8. **CTA** - Финальный призыв к действию
9. **Footer** - Навигация и ссылки

## 🚀 Как использовать

### Локальный просмотр

Просто откройте `index.html` в браузере:

```bash
# Из корня проекта
open docs/index.html

# Или используйте локальный сервер (рекомендуется)
cd docs
python -m http.server 8000
# Откройте http://localhost:8000 в браузере
```

### Развертывание

#### GitHub Pages

1. Перейдите в Settings репозитория
2. В разделе Pages выберите источник: `main` branch, `/docs` folder
3. Сохраните - сайт будет доступен по адресу `https://nickscherbakov.github.io/KhazarLLMs/`

#### Netlify

1. Войдите на netlify.com
2. Drag & drop папку `docs` в Netlify
3. Сайт будет автоматически развернут

#### Vercel

```bash
cd docs
vercel deploy
```
