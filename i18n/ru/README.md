# KhazarLLMs 🌟

> 🌐 **Языки:** [English](../../README.md) | [العربية](../ar/README.md) | [中文](../zh/README.md) | [Русский](README.md)

**Система управления коллективным творчеством ансамблей LLM**

> 🌐 **[Лендинг](../../docs/i18n/ru/index.html)** | 📚 **[Документация](USAGE_GUIDE.md)** | 💻 **[Примеры](../../examples/)**

Вдохновлённый «Хазарским словарём» Милорада Павича и его исследованием множественных перспектив, KhazarLLMs управляет ансамблем AI-агентов с различными личностями и ролями для совместной работы над творческими задачами. Подобно полифонической структуре Хазарского словаря, где множество голосов рассказывают взаимосвязанные истории, эта система объединяет различные AI-перспективы для исследования идей с разных сторон.

## 🎭 Философия

В Хазарском словаре истина возникает не из одной перспективы, а из взаимодействия многих голосов - христианских, исламских и иудейских источников, рассказывающих пересекающиеся, но различные истории. Аналогично, KhazarLLMs верит, что наиболее творческие и проницательные решения возникают из столкновения и синтеза множественных AI-перспектив, каждая со своей ролью и личностью:

- **Мечтатель** - Генерирует дикие, безграничные творческие видения
- **Критик** - Анализирует с острым взглядом и конструктивными вызовами
- **Синтезатор** - Сплетает разрозненные идеи в связные целые
- **Философ** - Исследует глубокие смыслы и более широкие контексты
- **Бунтарь** - Бросает вызов предположениям и нарушает конвенции
- **Архитектор** - Структурирует и организует идеи в реализуемые формы
- **Поэт** - Добавляет красоту и эмоциональный резонанс

## ✨ Возможности

- 🤖 **Множество агентских персон** - Каждый с уникальными творческими ролями и личностями

## 🚀 Быстрый старт

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/NickScherbakov/KhazarLLMs.git
cd KhazarLLMs

# Установите зависимости
pip install -r requirements.txt

# Опционально: Настройте API-ключи
cp .env.example .env
# Отредактируйте .env с вашими API-ключами
```

### Базовое использование

```python
import asyncio
from khazar_llms.agents.personas import DreamerAgent, CriticAgent, SynthesizerAgent
from khazar_llms.orchestration.ensemble import Ensemble
from khazar_llms.orchestration.session import CreativeSession

async def main():
    # Создайте агентов
    agents = [
        DreamerAgent(provider="mock"),
        CriticAgent(provider="mock"),
        SynthesizerAgent(provider="mock"),
    ]
    
    # Создайте ансамбль
    ensemble = Ensemble(agents=agents, max_iterations=3)
    
    # Запустите творческую сессию
    session = CreativeSession(ensemble)
    results = await session.run("Разработайте новую форму коммуникации")
    
    # Просмотрите результаты
    for msg in results["conversation"]:
        print(f"{msg.sender}: {msg.content}")

asyncio.run(main())
```

### Использование CLI

```bash
# Получите помощь
python -m khazar_llms.cli info

# Список доступных агентов
python -m khazar_llms.cli list-agents

# Запустите творческую задачу
python -m khazar_llms.cli create-task "Представьте библиотеку, существующую в нескольких измерениях"

# Используйте параллельный режим с конкретными агентами
python -m khazar_llms.cli --mode parallel --agents dreamer rebel poet create-task "Создайте новый музыкальный инструмент"

# Используйте с реальным LLM провайдером
python -m khazar_llms.cli --provider openai create-task "Разработайте образовательную систему будущего"
```

## 🏗️ Архитектура

### Основные компоненты

1. **Агенты** (`khazar_llms/agents/`)
   - Базовый класс агента с памятью и логикой ответа
   - Специализированные персоны с уникальными системными промптами
   - Абстракция LLM-клиента для множества провайдеров

2. **Оркестрация** (`khazar_llms/orchestration/`)
   - Управление ансамблем для координации агентов
   - Управление сессиями для запуска и сохранения совместной работы
   - Множество режимов разговора (последовательный, параллельный, дебатный, консенсусный)

3. **Утилиты** (`khazar_llms/utils/`)
   - LLM-клиент с абстракцией провайдера
   - Mock-провайдер для тестирования без затрат на API

## 🎨 Режимы разговора

- **Последовательный** - Агенты отвечают один за другим, опираясь на предыдущие ответы
- **Параллельный** - Все агенты отвечают одновременно на один и тот же контекст
- **Дебатный** - Агенты участвуют в структурированных взаимных обменах
- **Консенсусный** - Агенты явно работают над достижением согласия и синтеза
