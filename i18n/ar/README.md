# KhazarLLMs 🌟

> 🌐 **اللغات:** [English](../../README.md) | [العربية](README.md) | [中文](../zh/README.md) | [Русский](../ru/README.md)

**نظام لإدارة الإبداع الجماعي لمجموعات نماذج اللغة الكبيرة**

> 🌐 **[الصفحة المقصودة](../../docs/i18n/ar/index.html)** | 📚 **[التوثيق](USAGE_GUIDE.md)** | 💻 **[الأمثلة](../../examples/)**

مستوحى من "قاموس الخزر" لميلوراد بافيتش واستكشافه لوجهات نظر متعددة، يقوم KhazarLLMs بتنسيق مجموعة من وكلاء الذكاء الاصطناعي ذوي شخصيات وأدوار متميزة للتعاون في المهام الإبداعية. مثل البنية متعددة الأصوات لقاموس الخزر، حيث تروي أصوات متعددة قصصًا متشابكة، يجمع هذا النظام بين وجهات نظر مختلفة للذكاء الاصطناعي لاستكشاف الأفكار من زوايا عديدة.

## 🎭 الفلسفة

في قاموس الخزر، تنبثق الحقيقة ليس من منظور واحد بل من تفاعل أصوات كثيرة - مصادر مسيحية وإسلامية ويهودية تروي قصصًا متداخلة لكن مختلفة. وبالمثل، يؤمن KhazarLLMs بأن الحلول الأكثر إبداعًا وبصيرة تنبثق من تصادم وتوليف وجهات نظر متعددة للذكاء الاصطناعي، كل منها له دوره وشخصيته:

- **الحالم** - يولد رؤى إبداعية جامحة بلا حدود
- **الناقد** - يحلل بنظرة ثاقبة وتحديات بناءة
- **المركب** - ينسج الأفكار المتباينة في كليات متماسكة
- **الفيلسوف** - يستكشف المعاني العميقة والسياقات الأوسع
- **المتمرد** - يتحدى الافتراضات ويكسر الأعراف
- **المعماري** - يهيكل وينظم الأفكار في أشكال قابلة للتنفيذ
- **الشاعر** - يضيف الجمال والرنين العاطفي

## ✨ المميزات

- 🤖 **شخصيات وكلاء متعددة** - كل منها له أدوار وشخصيات إبداعية فريدة
- 🎯 **تنسيق مرن** - أوضاع تسلسلية وموازية ومناظرة وإجماع
- 🔄 **التحسين التكراري** - جولات محادثة متعددة لتطوير الأفكار
- 💾 **إدارة الجلسات** - حفظ ومراجعة الجلسات الإبداعية
- 🎨 **مستقل عن المزود** - يعمل مع OpenAI و Anthropic أو وضع المحاكاة
- 🛠️ **CLI وPython API** - استخدم عبر سطر الأوامر أو ادمج في الكود الخاص بك

## 🚀 البدء السريع

### التثبيت

```bash
# استنسخ المستودع
git clone https://github.com/NickScherbakov/KhazarLLMs.git
cd KhazarLLMs

# ثبت التبعيات
pip install -r requirements.txt

# اختياري: إعداد مفاتيح API
cp .env.example .env
# قم بتحرير .env بمفاتيح API الخاصة بك
```

### الاستخدام الأساسي

```python
import asyncio
from khazar_llms.agents.personas import DreamerAgent, CriticAgent, SynthesizerAgent
from khazar_llms.orchestration.ensemble import Ensemble
from khazar_llms.orchestration.session import CreativeSession

async def main():
    # أنشئ الوكلاء
    agents = [
        DreamerAgent(provider="mock"),
        CriticAgent(provider="mock"),
        SynthesizerAgent(provider="mock"),
    ]
    
    # أنشئ المجموعة
    ensemble = Ensemble(agents=agents, max_iterations=3)
    
    # شغل جلسة إبداعية
    session = CreativeSession(ensemble)
    results = await session.run("صمم شكلاً جديدًا للتواصل")
    
    # اعرض النتائج
    for msg in results["conversation"]:
        print(f"{msg.sender}: {msg.content}")

asyncio.run(main())
```

### استخدام CLI

```bash
# احصل على المساعدة
python -m khazar_llms.cli info

# اعرض قائمة الوكلاء المتاحين
python -m khazar_llms.cli list-agents

# شغل مهمة إبداعية
python -m khazar_llms.cli create-task "تخيل مكتبة موجودة في أبعاد متعددة"

# استخدم الوضع الموازي مع وكلاء محددين
python -m khazar_llms.cli --mode parallel --agents dreamer rebel poet create-task "أنشئ آلة موسيقية جديدة"

# استخدم مع مزود LLM حقيقي
python -m khazar_llms.cli --provider openai create-task "صمم نظام تعليم للمستقبل"
```

## 🏗️ البنية

### المكونات الأساسية

1. **الوكلاء** (`khazar_llms/agents/`)
   - فئة الوكيل الأساسية مع الذاكرة ومنطق الاستجابة
   - شخصيات متخصصة مع مطالبات نظام فريدة
   - تجريد عميل LLM لمزودين متعددين

2. **التنسيق** (`khazar_llms/orchestration/`)
   - إدارة المجموعة لتنسيق الوكلاء
   - إدارة الجلسات لتشغيل وحفظ التعاون
   - أوضاع محادثة متعددة (تسلسلية، موازية، مناظرة، إجماع)

3. **الأدوات** (`khazar_llms/utils/`)
   - عميل LLM مع تجريد المزود
   - مزود محاكاة للاختبار بدون تكاليف API

## 🎨 أوضاع المحادثة

- **تسلسلي** - يستجيب الوكلاء واحدًا تلو الآخر، بناءً على الاستجابات السابقة
- **موازي** - يستجيب جميع الوكلاء في نفس الوقت لنفس السياق
- **مناظرة** - ينخرط الوكلاء في تبادلات منظمة ذهابًا وإيابًا
- **إجماع** - يعمل الوكلاء بشكل صريح نحو الاتفاق والتوليف
